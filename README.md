# Referto CSEN

Web app installabile (iPhone/iPad) per compilare il referto elettronico delle gare di pallavolo CSEN.

## Pubblicazione su GitHub Pages
1. Crea un repository (es. `referto-csen`) e carica tutti i file di questa cartella nella radice.
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, cartella `/ (root)`.
3. Dopo un minuto l'app è su `https://<utente>.github.io/referto-csen/`.

## Installazione su iPhone/iPad
Apri il link in Safari → Condividi → "Aggiungi alla schermata Home". L'app funziona anche offline.
I dati restano sul dispositivo: usa "Esporta backup" per conservarli.

## PDF del referto
Scheda Referto → "Stampa / salva PDF" → nel foglio di stampa allarga l'anteprima (pizzica) o tocca Condividi → "Salva su File".
